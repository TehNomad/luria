## 2. D031, inline

For a deletion of `[s, e)`, `w = e − s`, on a **linear** template of length
`n`, with bound `b = request.min_annealing_overlap()`:

- forward primer = template `[e, e + f)`; reverse primer = reverse complement
  of template `[s − r, s)`.
- both primers start at `first = max(b, MIN_REVERSE)` (`MIN_REVERSE` is 15).
- **no design possible** if `w + 2 * first > n`:
  `NoPrimerDesignPossible { template_length: n, smallest_pair: w + 2 * first }`.
- **no design fits**, using `NoPrimerDesignFits` with `edit_start: s`,
  `edit_end: e`:
  - `s < first` → `FivePrimeAvailability { available: s, needed: first }`;
  - `n − e < first` → `ThreePrimeAvailability { available: n − e, needed: first }`;
  - both pushed if both apply, 5′ first, then return;
  - then every non-`ACGT` base in `[s − first, s)` and then in
    `[e, e + first)`, ascending, as `AmbiguousTemplateBase`, then return.
- availability: forward counts `ACGT` bases rightward from `e`, reverse
  leftward from `s`, stopping at an ambiguity code or the template's end,
  exactly as the substitution path counts from `end` and `boundary`.
- sizing: **D030's loops, unchanged**: floor 55, G/C end below 63, forward
  first, 5 °C balance. Both Tms are on the matched basis
  (`melting_temperature(&p, &p, buffer)`), since neither primer has a
  mismatch.
- Ta, `tm_balance_met` and warnings are computed as for substitutions.
- A circular template is refused before any of this, as for substitutions.

## 3. Required changes, all in `crates/core/src/primer_design.rs`

### 3.1 Generalise `Sizer` (behaviour-preserving)

Replace its fields with:

```rust
struct Sizer {
    wild_type: Vec<char>,
    forward_letters: Vec<char>, // edited for a substitution, wild_type for a deletion
    forward_start: u64,         // boundary, or e
    forward_anchor: u64,        // end, or e: the length argument counts from here
    reverse_end: u64,           // boundary, or s
    forward_mismatched: bool,   // true for a substitution
    buffer: BufferModel,
}
```

- `forward(n)` = `forward_letters[forward_start .. forward_anchor + n]`
- `forward_site(n)` = `wild_type[forward_start .. forward_anchor + n]`
- `reverse(n)` = reverse complement of `wild_type[reverse_end − n .. reverse_end]`
- `forward_tm(n)`: `melting_temperature_or_matched(forward, site, buffer)` when
  `forward_mismatched`, else `melting_temperature(&forward, &forward, buffer)`.
- `reverse_tm` unchanged.

The substitution path builds it with `forward_letters: result.edited().letters()`,
`forward_start: boundary`, `forward_anchor: end`, `reverse_end: boundary`,
`forward_mismatched: true`.

### 3.3 Design a deletion

- Remove the block that refuses `result.is_deletion()` ("deletion primer
  design is not implemented yet").
- After the circular-template check and **before** `replacement_region`, add:
  `if result.is_deletion() { return design_deletion(template, result, request); }`
- `fn design_deletion(template: &Sequence, result: MutationResult, request:
  PrimerDesignRequest) -> Result<PrimerDesign, DomainError>` implements §2.
  `s` and `e` come from `result.target_coordinates()` (first, last + 1). It
  builds the `Sizer` with `forward_letters: wild_type`, `forward_start: e`,
  `forward_anchor: e`, `reverse_end: s`, `forward_mismatched: false`, calls
  `size_pair(&sizer, first, first, forward_available, reverse_available, &fits)`,
  then builds the forward span `[e, e + f)` and the reverse span `[s − r, s)`.
  It calls `construct_primer` for both, then `assemble_pair` and
  `require_design_constraints` as the substitution path does.
