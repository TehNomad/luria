## 2. The source capture (fetched by the planner)

`target/a7/kazusa-316407-standard.html` was downloaded on 2026-10-16 from
<https://www.kazusa.or.jp/codon/cgi-bin/showcodon.cgi?species=316407&aa=1&style=N>.
It is 4583 bytes, with SHA-256
`350caaf43968dc2fe8638574f0f980b073070daf18d259ea094bcbea9f5e02fc`. Its
`<PRE>` block holds 64 rows, `[triplet] [aa] [fraction] [per thousand]
([count])`, with `U` for `T`, and the counts sum to 1372057. Confirm the size
and hash before using it. If either differs, stop.
